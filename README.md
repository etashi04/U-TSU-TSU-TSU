# UTSUTSUTSU 한국어 패치

Steam판 **UTSUTSUTSU** 비공식 한국어 패치 저장소입니다.

현재 정식 배포 버전은 `v1.0.1`이며 Steam 빌드 25706167, Windows x64 환경에서 확인했습니다.

## 배포본

[최신 릴리스](https://github.com/etashi04/U-TSU-TSU-TSU/releases/latest)에서 다운로드하세요.

- `UTSUTSUTSU_Korean_Patch_v1.0.1.zip`: GUI 설치기를 통한 자동 설치·원본 복구
- `UTSUTSUTSU_Korean_Patch_Manual_v1.0.1.zip`: 게임 실행 파일이 있는 폴더에 직접 복사
- `SHA256SUMS.txt`: 배포 ZIP 무결성 확인용 체크섬

게임을 종료한 상태에서 설치하세요. 저장 데이터는 수정하지 않습니다.

## 자동 설치

1. Auto ZIP을 모두 압축 해제합니다.
2. `한국어 패치 설치기.exe`를 실행합니다.
3. `UTSUTSUTSU.exe`가 있는 게임 폴더를 확인하고 설치합니다.

## 수동 설치

1. Manual ZIP의 `패치파일` 폴더를 엽니다.
2. 안의 파일과 폴더를 `UTSUTSUTSU.exe`가 있는 경로에 붙여넣습니다.
3. 게임을 실행합니다.

## 복구

- 자동판: 같은 설치기에서 `원본 복구`를 선택합니다.
- 수동판: Steam 파일 무결성 검사를 권장합니다.

## 오류 해결

### 스마트 앱 컨트롤이 설치기 또는 게임 실행을 차단할 때

이 패치의 설치 EXE와 일부 DLL은 디지털 서명이 없어 Windows 스마트 앱 컨트롤에서 차단될 수 있습니다. 오류 안내에서 스마트 앱 컨트롤에 의한 차단인지 먼저 확인하세요.

해당 기능이 차단 원인이라면 아래 설정을 끈 뒤 다시 실행할 수 있습니다. **이 설정은 PC 전체의 앱 실행 보호 수준을 낮추므로 변경 여부는 사용자가 판단해 주세요.** 변경 전 화면에 표시되는 재활성화 관련 안내도 확인하세요.

1. **Windows 보안**을 엽니다.
2. **앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정**으로 이동합니다.
3. 설정 변경을 선택한 경우 **끄기**로 바꾼 뒤, 차단됐던 설치기 또는 게임을 다시 실행합니다.

설치 EXE만 차단된다면 **수동 설치판**을 이용할 수 있습니다. 다만 게임이 불러오는 패치 DLL 자체가 차단되면 **수동 설치로도 해결되지 않습니다.**

차단 원인이 다르거나 문제가 계속되면 오류 문구와 차단된 파일명을 확인한 뒤, 저장소의 [이슈(Issues) 탭](https://github.com/etashi04/U-TSU-TSU-TSU/issues)에 제보해 주세요. 로그·스크린샷을 공개할 때는 사용자 이름과 개인 경로를 가려 주세요.
