UTSUTSUTSU 한국어 패치 v1.0.1

이 패치는 Steam판 빌드 25706167용 비공식 한국어 패치입니다.
비상업적으로 제작되어 무료 배포되며 원작자·개발사·배급사와 무관합니다.

[자동 설치]
1. ZIP을 원하는 폴더에 모두 압축 해제합니다.
2. 「한국어 패치 설치기.exe」를 실행합니다.
3. 게임 설치 폴더를 확인하고 「한국어 패치 설치」를 누릅니다.
4. Steam에서 게임을 평소처럼 실행합니다.

[수동 설치]
1. Steam 라이브러리에서 게임 우클릭 → 관리 → 로컬 파일 보기를 엽니다.
2. ZIP 안 「패치파일」 폴더의 내용물을 게임 설치 폴더에 복사합니다.
3. UTSUTSUTSU.exe와 winhttp.dll이 같은 위치에 있어야 합니다.

[삭제·복구]
- 자동 설치판은 같은 설치기에서 「원본 복구」를 누릅니다.
- 수동 설치판은 Steam 파일 무결성 검사를 이용하는 것을 권장합니다.
- 저장 데이터는 패치 설치·복구 대상에 포함되지 않습니다.
